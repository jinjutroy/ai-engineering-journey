Phase 00 — Knowledge Check

This check tests the core AI-system mental model. It is self-assessment, not a coding test.

problem → policy/risk → data/context → mechanism → output → validation/decision → action → monitoring/feedback

Core questions

1. Which statement is most accurate?
2. What is a model?
3. What is context?
4. Which is the correct system flow?
5. When is ordinary software often better than AI?
6. Does valid JSON prove that a model response is correct?
7. What should happen before a model output triggers a sensitive action?
8. Which is a context failure?
9. Why is monitoring needed after deployment?
10. What is the best first question for choosing ML, DL, or GenAI?
Show explanations
1. AI is the broad field; ML and DL describe learning methods; GenAI describes content generation.
2. A model is one component that turns input into output; it does not guarantee correctness.
3. Context is request-time information, including instructions, history, evidence, and tools.
4. A useful system starts from a problem and continues through validation, action, and monitoring.
5. Rules are preferred when the policy is stable, explicit, and exact.
6. Valid structure is not the same as correct, safe, or authorized content.
7. Sensitive actions need validation, policy enforcement, and sometimes human approval.
8. Context can be incomplete, irrelevant, stale, conflicting, malicious, or sensitive.
9. Real-world inputs, behavior, dependencies, quality, latency, and cost change after deployment.
10. Choose technology from the task, data, constraints, and acceptable failure—not popularity.
