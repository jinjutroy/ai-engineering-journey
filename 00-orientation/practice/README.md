# Phase 00 Practice

Phase 00 is complete when the learner can apply the core flow to a concrete
feature. No implementation or runtime setup is required.

## Practice sequence

1. Choose one familiar feature.
2. Define the user or business decision.
3. Draw the end-to-end AI system flow.
4. Identify data, context, model output, and product action.
5. Decide whether to use rules, ML, DL, GenAI, a hybrid, or no AI.
6. Analyze five failure scenarios.
7. Define validation, fallback, ownership, and monitoring.
8. Complete the [knowledge check](../knowledge-check/index.html).
9. Record the result in [phase00-evidence.md](../phase00-evidence.md).

## Suggested features

- Spam detection
- Product recommendation
- Document extraction
- Finance review
- Internal knowledge assistant
- Code review assistant

## Review questions

- What is the smallest useful version of this feature?
- What would a non-AI solution look like?
- What is the model allowed to suggest?
- What is the model not allowed to do?
- Which failures can be detected automatically?
- Where must a human approve or override the result?
